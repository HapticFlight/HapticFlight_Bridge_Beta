# OH-58D ShakeIt profile

`DCS World - DCS OH-58D - DCSExtra Baseline v0.1.siprofile` is a conservative
Kiowa Warrior baseline built from the UH-60 v1.8.8 cue architecture. The
adapter uses collective argument 3 and the four suspension arguments declared
by the module FM. Rotor speed uses a bounded engine-RPM proxy until a live log
can validate a dedicated NR source; the baseline frequencies use 395 RPM at
100% Nr and the OH-58D four-blade rotor.

Validate startup, parked-hot, cruise, climb/descent, maneuver, four-skid
touchdown and scrub, M3P, Hydra, Hellfire/ATAS, and countermeasure cases before
promotion.
