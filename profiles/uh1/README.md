# UH-1H ShakeIt profile

`DCS World - DCS UH-1H - DCSExtra Baseline v0.1.siprofile` is a conservative
Huey baseline built from the UH-60 v1.8.8 cue architecture. It uses the
official module's rotor tach/phase, collective, normalized torque gauge,
weight-on-skids, crew-gun, rocket, and countermeasure telemetry.

The 1/rev and two-blade-pass layers remain separate; the redundant structural
2/rev layer is intentionally removed to prevent frequency stacking at 10.8 Hz.
Validate startup, parked-hot, cruise, climb/descent, skid touchdown/scrub,
M134/M60, heavy gun or grenade launcher, rockets, and flares before promotion.
