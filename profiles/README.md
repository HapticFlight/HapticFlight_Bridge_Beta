# Profiles

Latest realism test: six V2 test.19 profiles under `downloads/realism-test19`.
These require Haptic Engine 1.7.1. Test.7 through test.18 remain separate
comparison stages, and application test.121 remains the known-working rollback.

This directory contains versioned, importable SimHub and ShakeIt profiles that
belong to this project. The release bundle ships the current UH-60L profile as
the first recording-replayed reference; other aircraft profiles remain
development artifacts until their telemetry and seat calibration are complete.

Gain safety: start with the amplifier volume low and SimHub master/output gain
at 50% or lower. Test one effect at a time and raise levels gradually. Stop if
the shaker clips, overheats, or feels unsafe.

Each airframe family has its own folder. Preserve historical revisions so a user
can return to a known working profile after testing a newer calibration.
