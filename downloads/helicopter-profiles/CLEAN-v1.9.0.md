# Clean UH-60L / DAP profile

Import `DCS World - DCS UH60L - DCSExtra Clean v1.9.0.siprofile` into SimHub ShakeIt Bass Shakers and select it manually. Disable the previous profile and retain your existing sound-card/channel routing.

This clean copy preserves every effect, formula, gain and frequency from the repository UH-60 v1.9.0 reference. All 41 effects and five groups are enabled. Only the profile identity, description, automatic aircraft assignment and output-settings inclusion have been changed. It has a new profile ID and excludes device output settings.

Source equivalence and the UH-60 regression suite were checked. This does not confirm live DCS telemetry, shaker output or tactile calibration. Unsupported or missing telemetry can still leave an enabled effect silent.
