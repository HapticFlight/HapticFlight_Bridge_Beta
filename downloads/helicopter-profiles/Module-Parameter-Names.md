# Module parameter names

Exact, case-sensitive names found in the supplied readable Lua source. Named parameters come from get_param_handle, parameter_name, element_params and readParameter/writeParameter. Panel controllers are listed separately because they are code names, not get_param_handle names.

MH-6J shares the AH-6J module source; DAP shares UH-60L. Presence in source does not prove runtime accessibility. Compiled-module internals and dynamically constructed names are not exhaustively recoverable from these files.
