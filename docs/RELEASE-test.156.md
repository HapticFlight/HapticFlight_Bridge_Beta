# HapticFlight Bridge 0.1.0-test.156

## Installation

1. Run `HapticFlight-Bridge-Setup-0.1.0-test.156.exe`.
2. Open the app and choose **Update components** if your DCS and SimHub paths are already configured.
3. In SimHub, import `DCS-AH-6J-Haptic-Engine-v2.0.0-AH6-v1.7-Rotor-Response.siprofile` and disable any older AH-6J profile.

## Change log

- **Flights:** Removed the built-in graph, debrief, and replay analyzer. The recorder and **Open folder** remain for saved telemetry files.
- **AH-6J v1.7:** Separates steady rotor presence from manoeuvre response while bounding each continuous rotor layer.
- **Archive:** v1.6 remains in `Profiles\Archive\AH-6J` for rollback.
