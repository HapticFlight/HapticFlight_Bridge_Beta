# HapticFlight Bridge 0.1.0-test.140

## Installation instructions

1. Run `HapticFlight-Bridge-Setup-0.1.0-test.140.exe`.
2. Launch HapticFlight Bridge from the final Setup page or the Start menu.
3. The installer updates only HapticFlight Bridge. DCS Hook and SimHub plugin installation remain separate in-app choices.

## Change log

- Added a telemetry view with synchronized replay cursor, signal selection, raw or normalized scale, and source labels.
- Added a debrief view with a repeatable event table, peak and average intensity, frequency, phase, and time range.
- Added findings for peak effect concurrency, touchdown and rotor-droop conditions, plus effects that never fired.
- Added recording comparison metrics for duration, peak concurrency, touchdown, and rotor droop.
- Updated the launcher palette to use a cooler blue primary color; orange is reserved for warnings and weapons activity.
- Effect intensity and combined load remain replayed analysis of recorded telemetry and profiles; they do not measure the final SimHub mix or physical shaker output.

## Beta notice

This local test build is unsigned. Windows App Control may block it on protected PCs; do not disable security protections to force it to run.
