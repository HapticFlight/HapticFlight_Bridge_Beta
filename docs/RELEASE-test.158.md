# HapticFlight Bridge 0.1.0-test.158

## Change log

- Adds a diagnostic probe for the AH-6J/MH-6J rotor RPM parameter to flight recordings. The value does not control haptic effects.

## Test

Install the update, then select **Update components** with DCS and SimHub closed. Record a cold start, hold governed RPM for 15 seconds, and record shutdown. Note approximate times and cockpit RPM readings, then share the recording.

This test build is unsigned; Windows App Control may block it on protected PCs.
