# HapticFlight Bridge 0.1.0-test.137 — app-only Setup

Download HapticFlight-Bridge-Setup-0.1.0-test.137.exe and run it directly.
Setup installs only the HapticFlight Bridge application and offers to launch it
on the final page. It does not modify DCS or SimHub during application setup.

Inside the app, select your DCS Saved Games profile and SimHub folder. Install
or uninstall the DCS Hook and SimHub plugin separately, or choose Install
everything. Close DCS and SimHub before changing either component. Once both
are installed, HapticFlight Bridge can be closed while DCS and SimHub exchange
telemetry.

Application removal cleans up any remaining Hook or plugin installed through
HapticFlight Bridge. Your recordings and unrelated DCS/SimHub files are kept.

This beta is unsigned. Windows App Control may block Setup or the installed
app on protected PCs. Do not disable security protections to force it to run.
Live DCS/SimHub hardware output and protected-PC installation remain unverified.
