# HapticFlight Bridge 0.1.0-test.142

## Installation instructions

1. Run `HapticFlight-Bridge-Setup-0.1.0-test.142.exe`.
2. Launch HapticFlight Bridge from the final Setup page or the Start menu.
3. The installer updates only HapticFlight Bridge. DCS Hook and SimHub plugin installation remain separate in-app choices.

## Change log

- Replaced the misleading suggested-gain display with an explicit SimHub tuning handoff.
- Replaced the misleading Test effect control with a copyable SimHub test handoff; it does not trigger a shaker.
- Added a copyable one-change A/B tuning worksheet for repeatable profile tests.
- Added profile-tuning instructions that distinguish recorded/modelled evidence from SimHub and physical-output validation.
