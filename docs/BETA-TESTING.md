# Public beta testing

Thank you for testing HapticFlight Bridge. This beta validates installation,
telemetry connection, profile coverage, and tactile behavior across different
hardware and DCS modules.

## Before reporting a problem

1. Confirm the launcher and installed bridge version.
2. Confirm the DCS module, map, and mission type.
3. Confirm the matching SimHub profile is the only overlapping profile enabled.
4. Note your SimHub version and haptic hardware.
5. Reproduce the issue if it is safe to do so.

## Issue report checklist

- What you expected to happen
- What happened instead
- HapticFlight Bridge version
- DCS aircraft and map
- SimHub version
- Whether `DCSExtra.Connected` was true
- Relevant launcher message or screenshot
- Optional anonymized recording, if it helps and you are comfortable sharing it

Never include account tokens, private paths you do not wish to disclose, or
personal data in a public issue.
