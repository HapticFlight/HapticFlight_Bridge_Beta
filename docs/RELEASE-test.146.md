# HapticFlight Bridge 0.1.0-test.146

## Installation instructions

1. Run `HapticFlight-Bridge-Setup-0.1.0-test.146.exe`.
2. Launch HapticFlight Bridge from the final Setup page or the Start menu.
3. The installer updates only HapticFlight Bridge. DCS Hook and SimHub plugin installation remain separate in-app choices.

## Change log

- Fixed the Dashboard setup display: only components installed and matching the current package are green.
- Missing or different Hook and SimHub plugin components now show amber `Ready to install`, matching the top-right setup count.

## Beta notice

This beta is unsigned. Windows App Control may block it on protected PCs; do not disable security protections to force it to run.
