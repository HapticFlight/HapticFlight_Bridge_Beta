# AH-6J / MH-6J v1.5 rotor baseline

Import `DCS-AH-6J-Haptic-Engine-v2.0.0-AH6-v1.5-Rotor-Baseline.siprofile`.

v1.5 makes the restrained 1/rev and 2/rev rotor layers normal defaults and
retains the v1.4 touchdown limiter. It replaces the AH-6J v1.3/v1.4 files at
the top level; those files remain in `Profiles\Archive\AH-6J` for deliberate
rollback.

Use one AH-6J profile at a time. Validate with a hover, climb, bank, descent,
soft landing, and firm landing before changing gains.
