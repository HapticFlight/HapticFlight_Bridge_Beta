# HapticFlight Bridge 0.1.0-test.147

## Installation instructions

1. Run `HapticFlight-Bridge-Setup-0.1.0-test.147.exe`.
2. Launch HapticFlight Bridge from the final Setup page or the Start menu.
3. The installer updates only HapticFlight Bridge. The DCS Hook and SimHub plugin remain separate in-app choices.

## Change log

- Fixed Setup upgrades that could fail verification because an older versioned release note remained in the app folder.
- Existing DCS Hook and SimHub plugin files now remain recognised after an app update. If they differ from the current package, the app shows `Update available` rather than `Not installed`.
- The top-right indicator now separates missing setup from component updates.

## Beta notice

This beta is unsigned. Windows App Control may block it on protected PCs; do not disable security protections to force it to run.
