# HapticFlight Bridge 0.1.0-test.148

## Installation instructions

1. Run `HapticFlight-Bridge-Setup-0.1.0-test.148.exe`.
2. Launch HapticFlight Bridge from the final Setup page or the Start menu.
3. The installer updates only HapticFlight Bridge. DCS Hook and SimHub plugin installation remain separate in-app choices.

## Change log

- Fixed installed-package verification when legacy or comparison `.siprofile` files are present in the app's bundled Profiles folder.
- Fresh downloaded packages still require every file to match the release manifest.
- No SimHub-imported profiles are changed or deleted.

## Beta notice

This beta is unsigned. Windows App Control may block it on protected PCs; do not disable security protections to force it to run.
