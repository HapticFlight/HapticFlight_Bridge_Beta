# HapticFlight Bridge 0.1.0-test.155

## Installation

1. Run `HapticFlight-Bridge-Setup-0.1.0-test.155.exe`.
2. Open the app and choose **Update components** if your DCS and SimHub paths are already configured.
3. In SimHub, import `DCS-AH-6J-Haptic-Engine-v2.0.0-AH6-v1.6-Rotor-Gain-Reduction.siprofile` and disable any older AH-6J profile.

## Change log

- **AH-6J v1.6:** Reduced the complete continuous-rotor stack: 1/rev is 9%, 2/rev is 6%, and 5/rev blade-pass is 24%.
- **Improves:** Keeps rotor texture tied to manoeuvres without overwhelming a high-output tactile device.
- **Archive:** v1.5 is retained in `Profiles\Archive\AH-6J` for rollback.
