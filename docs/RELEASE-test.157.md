# HapticFlight Bridge 0.1.0-test.157

This correction keeps the AH-6J v1.7 Rotor Response baseline profile and fixes updater-cache validation when a retired profile or reference document is absent after an upgrade.

1. Run `HapticFlight-Bridge-Setup-0.1.0-test.157.exe`.
2. Open the launcher and confirm the version is `0.1.0-test.157`.
3. The v1.7 AH-6J profile remains available in the installed `Profiles` folder.
