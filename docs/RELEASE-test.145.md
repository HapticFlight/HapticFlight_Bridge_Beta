# HapticFlight Bridge 0.1.0-test.145

## Installation instructions

1. Run `HapticFlight-Bridge-Setup-0.1.0-test.145.exe`.
2. Launch HapticFlight Bridge from the final Setup page or the Start menu.
3. The installer updates only HapticFlight Bridge. DCS Hook and SimHub plugin installation remain separate in-app choices.

## Change log

- Fixed Flights analysis charts crashing during transient window or tab layout changes.
- Reworked the Flight Debrief into a flight story with coverage, peak-overlap evidence, an A/B experiment suggestion, and a supporting event log.
- Added AH-6J v1.1 calibration: direct rotor-phase handling, torque-based load input, guarded VRS and ground-effect cues, and corrected M134 recognition.
- Added the calibrated AH-6J SimHub profile and validation tooling.

## Beta notice

This local test build is unsigned. Windows App Control may block it on protected PCs; do not disable security protections to force it to run.
