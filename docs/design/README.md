# Design evidence

This folder contains visual design references and QA evidence for the Windows
launcher. It is not end-user documentation.

- `launcher-ui-qa.md` records the review outcome and links to supporting captures.
- `ux-audits/` contains dated or numbered visual-review captures.
- The remaining PNG files are design references and approved implementation
  comparisons.

Keep new evidence under `ux-audits/<audit-name>/` and update
`launcher-ui-qa.md` when a finding is closed or a new design decision is made.
