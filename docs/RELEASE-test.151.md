# HapticFlight Bridge 0.1.0-test.151

## Installation instructions

1. Run `HapticFlight-Bridge-Setup-0.1.0-test.151.exe`.
2. Open the installed `Profiles` folder. The current aircraft profiles remain
   at its root.
3. AH-6J and MH-6J profiles left by earlier releases are moved safely to their
   respective `Profiles\Archive\<aircraft>` folder during the Setup upgrade.

## Change log

- Migrates prior top-level AH-6J profiles into `Profiles\Archive\AH-6J`.
- Migrates prior top-level MH-6J profiles into `Profiles\Archive\MH-6J`.
- Retains prior files as rollback copies; no profile is deleted.
