# HapticFlight Bridge 0.1.0-test.143

## Installation instructions

1. Run `HapticFlight-Bridge-Setup-0.1.0-test.143.exe`.
2. Launch HapticFlight Bridge from the final Setup page or the Start menu.
3. The installer updates only HapticFlight Bridge. DCS Hook and SimHub plugin installation remain separate in-app choices.

## Change log

- Fixed the Flights dashboard grid so the Telemetry and Debrief views occupy their own rows instead of overlapping the selected-effect panel.
- Added a regression check that rejects any Flights layout without rows for all views.
- Replaced the generic blue accent with a restrained warm-graphite and amber system. This is a palette correction, not a replacement for the forthcoming structural redesign.

## Beta notice

This local test build is unsigned. Windows App Control may block it on protected PCs; do not disable security protections to force it to run.
